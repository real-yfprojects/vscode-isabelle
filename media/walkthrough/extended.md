# What the extended server adds

- **Find Theorems** and constants, in the Query panel
- **Theories** and **Timing** views: what is checked, what is slow
- **Simplifier Trace** and **Graph View** panels
- **Indentation** as in Isabelle/jEdit, on Enter and on Format Selection
- **Colours** for constants, types and classes in checked terms
- **Session images** for projects that import from outside their parent session

It is Isabelle's own language server with this extension's additions, loaded
in front of your installation, which stays unmodified. Untick the setting to go back.
