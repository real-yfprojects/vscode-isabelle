# The Infoview

The goals and messages of the command at the cursor, in the bottom panel.

| Button | What it does |
|---|---|
| Pin | keeps this command's goals in view while you work elsewhere |
| Pause | stops following the cursor |
| Open in Editor | shows the Infoview in a tab beside the theory |

Drag the Infoview into a side bar if you prefer it next to the text.

Output of commands like `find_theorems`, `value` or `term` appears here too.
